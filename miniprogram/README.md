# 冷库冷量计算微信小程序

青岛冷锋节能工程有限公司 · 专业冷库热负荷计算工具

## 📱 项目简介

本项目是冷库冷量计算软件的微信小程序版本，将原 Web 版的全部计算功能移植到微信小程序平台，方便工程师在手机上随时随地进行冷库冷量计算和设备选型。

## 🚀 使用方法

### 1. 下载微信开发者工具
前往 [微信公众平台](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 下载并安装「微信开发者工具」。

### 2. 导入项目
- 打开微信开发者工具
- 选择「导入项目」
- 项目目录选择本文件夹 `miniprogram`
- AppID 可选择「测试号」（或填入你自己的小程序 AppID）
- 点击「导入」

### 3. 预览和调试
- 导入后即可在模拟器中看到运行效果
- 点击「预览」生成二维码，用手机微信扫码即可在真机上体验

### 4. 发布上线
- 在微信公众平台注册小程序账号，获取 AppID
- 将 `project.config.json` 中的 `appid` 改为你的小程序 AppID
- 在开发者工具中点击「上传」，填写版本号和描述
- 登录微信公众平台，提交审核，审核通过后即可发布

## ✨ 功能特性

### 七大计算模块
1. **基本信息**：库房尺寸、温度、湿度、安全系数
2. **围护结构**：6种保温板材可选，自动计算K值，各部位独立配置
3. **货物负荷**：冷却显热 + 冻结潜热 + 包装材料 + 运载工具
4. **通风换气**：湿空气焓值自动计算（Magnus公式）
5. **操作管理**：人员散热、照明、设备、开门热负荷
6. **电机热负荷**：冷风机及库内电机运行热量
7. **计算结果**：负荷汇总、柱状图、设备选型、报告导出
